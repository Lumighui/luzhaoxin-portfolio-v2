# 卢朝鑫的作品小屋

一个无需安装依赖的个人作品集与内容管理页面。默认使用 C · 索引档案版式，以深咖啡、炭褐、奶油与琥珀色构成暖色视觉；作品与图片保存在当前浏览器的 IndexedDB 中。

网站采用连续的三阶段入口：

1. **玻璃立方体序章**：暖调 3D 场景，使用程序化渐变背景，巨字被可拖拽旋转的玻璃立方体折射。
2. **小猫自我介绍**：以本地视频介绍 AI 与作者共同创建、记录作品的小屋。
3. **作品小屋**：以 React Bits CircularCarousel 的圆形空间轮播展示作品，同时保留全部作品管理功能和互动作品。

封面视频为 `assets/cat-intro.mp4`，静态回退与海报为 `assets/cat-intro-poster.jpg`。WebGL 加载失败时会自动显示 CSS 立方体回退画面。

当前收录两件真实作品：

- **我和我的AI——AI agent使用情况**
- **MLP学习参数的实现和可视化**

它们都不是单纯的外链卡片：完整互动页面已经打包在小屋内部，并采用相同的暖色体系。

## 本地运行

双击 `start-site.cmd`，脚本会启动本地服务器并打开：

```text
http://127.0.0.1:4173/
```

也可以在本目录手动运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

关闭启动脚本的命令行窗口后，本地服务器会停止。

## 使用方法

1. 点击右上角“新增作品”。
2. 填写“板块大标题”。选择已有名称会把作品放入该板块；输入新名称会自动创建板块。
3. 填写作品标题、简介、正文、标签和日期。
4. 上传图片。第一张图是封面，其余图片会出现在作品详情页。
5. 网址作品的链接填写格式为：`链接名称 | https://example.com`。每行一个链接。
6. 点击“保存作品”后，内容立即出现在首页。

点击作品卡片上的“进入互动作品”，会在小屋内部打开完整的 AI agent 使用记录。该页面不依赖 `8765` 端口，也不会把访客带到外部网址。

MLP 作品来自用户提供的公开页面 `https://lumighui.github.io/mlp-neural-flight/`，项目本身是纯静态页面。小屋保留了七站航线、Canvas 动画、参数表和键盘控制，不依赖外部 API 或原站点。

作品卡片上的“编辑”“删除”和上下箭头可以直接更新、删除或调整顺序。右上角齿轮中可以修改头像、站名、简介，重命名或删除板块，以及导出和导入完整 JSON 备份。

## 三套版式

- **A · 侧栏编辑室**：固定左侧个人名片和导航，安静克制，适合图文记录。
- **B · 作品画廊**：封面更大，首页以视觉作品为主。
- **C · 索引档案（默认）**：强化标题和目录层级，适合作品较多、偏文字表达的个人站。

点击左侧或页面中的“切换版式”即可切换。当前选择会在下一次打开时保留。

进入作品小屋后，左侧栏底部的“回到介绍页”可重新进入小猫介绍阶段。

## 圆形作品轮播

作品展示层使用 React Bits 的 CircularCarousel，支持拖动、惯性、吸附、键盘方向键和无障碍播报。轮播卡片与下方作品索引均连接到原有作品详情、互动作品、编辑、排序和删除流程。

组件源码位于 `src/`。修改后重新生成 GitHub Pages 使用的静态文件：

```powershell
npm install
npm run build:carousel
```

发布时无需在 GitHub Actions 中运行构建，直接提交 `index.html`、CSS、JavaScript 与打包后的 `assets/circular-carousel.bundle.*` 即可。

## 数据与发布

当前版本是本地版：

- 作品、文字、设置和压缩后的图片都保存在当前浏览器。
- 换浏览器、换电脑或清除站点数据后，本地内容不会自动出现。
- 需要迁移时，请在“站点设置 → 备份与恢复”中导出 JSON，并在新浏览器中导入。
- 本地版本没有服务端登录。不要把当前编辑入口直接当作公开网站的权限系统。

后续发布时应把数据层替换为云端数据库与图片存储，并加入真正的管理员登录。现有作品字段、板块结构和备份格式可以直接作为迁移基础。

## 文件结构

```text

├─ index.html                 页面结构
├─ styles.css                 三套版式与响应式样式
├─ experience.css             三阶段入口与暖色视觉系统
```
